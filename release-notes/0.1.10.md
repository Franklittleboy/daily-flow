DailyFlow 0.1.10 is a local draft polish release for the TickTick-like workspace refresh.

- Navigation now uses the right text sidebar only, with the middle icon rail removed.
- The focus page has been reworked toward TickTick's pomodoro layout with mode tabs, a large central timer, overview cards, and focus history.
- Focus task binding is now visible from the pomodoro page, and paused time is excluded from saved focus-session duration.
- Stopwatch mode is available alongside the existing pomodoro countdown flow.
- Month and week calendar views are denser, with compact task rows, left-aligned task text, and clearer todo/completed colors.
- Month cells can show more tasks before the overflow marker, use faint Chinese lunar dates when available, and stretch to reduce bottom whitespace.
- Week view now has a week/day header, all-day task area, draggable divider, and a scrollable 0-24 time grid that defaults to 8 AM.
- Month and week calendar task details include completion and date controls.
