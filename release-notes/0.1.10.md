DailyFlow 0.1.10 is a local draft polish release for the TickTick-like workspace refresh.

- Navigation now uses the right text sidebar only, with the middle icon rail removed.
- The focus page has been reworked toward TickTick's pomodoro layout with mode tabs, a large central timer, overview cards, and focus history.
- Stopwatch mode is available alongside the existing pomodoro countdown flow.
- Calendar task bars now distinguish incomplete and completed tasks with separate status colors.
- Month and week calendar task details include completion and date controls.
