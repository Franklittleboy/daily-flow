# DailyFlow 0.1.1

This patch fixes a plugin loading failure in Obsidian.

## Fixed

- Fixed a bundled variable shadowing issue that caused `Cannot access 'core' before initialization`.
- Added a smoke test that verifies `main.js` can be loaded.
- Added a `default` export for better compatibility with Obsidian's plugin loader.

## Install Manually

1. Create `<vault>/.obsidian/plugins/daily-flow/`.
2. Copy these files into that folder:
   - `manifest.json`
   - `main.js`
   - `styles.css`
3. Enable DailyFlow in Obsidian community plugin settings.
