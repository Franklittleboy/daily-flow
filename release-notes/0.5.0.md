DailyFlow 0.5.0 合并了任务详情最新编辑体验，重点完善 Markdown 正文、任务侧栏和右键菜单。

- 新增任务侧栏和任务列表右键菜单，支持今天、明天、七天后、自定义日期和清除日期等快捷操作。
- 任务详情正文改为 Markdown 风格编辑，支持普通文本、无序列表、`- [ ]` 待办、分割线和删除线。
- 使用 CodeMirror 构建任务详情正文编辑器，改善中文输入法输入时的稳定性。
- 添加 DailyFlow 自有 slash 菜单，可插入待办、列表、分割线和删除线，并可在设置中配置命令。
- 优化任务标题、日期、正文、任务行对齐和图片预览拖拽缩放，让整体更接近 TickTick 的任务详情体验。
