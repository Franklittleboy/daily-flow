# DailyFlow 0.1.2

This patch fixes the default open location.

## Fixed

- DailyFlow now opens in the main Obsidian workspace instead of the right sidebar.
- This makes the task list, calendar, and focus pages visible without manually resizing the sidebar.

## Install Manually

1. Copy `manifest.json`, `main.js`, and `styles.css` into `<vault>/.obsidian/plugins/daily-flow/`.
2. Restart Obsidian or disable and re-enable DailyFlow.
3. Use the DailyFlow ribbon icon or command palette command `Open DailyFlow`.
