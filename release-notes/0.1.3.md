# DailyFlow 0.1.3

This patch improves the layout and task creation flow.

## Changed

- DailyFlow navigation is on the right side again.
- The main workspace now stays reserved for tasks, calendar, and focus content.
- Task lists include a direct add-task row.
- Month calendar cells show a direct `+ Add` affordance.
- Week view columns include a direct `+ Add task` affordance.
